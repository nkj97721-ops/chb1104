# 夜航浏览器

深色优先的 Android WebView 浏览器。

- 深色地址栏、导航栏和状态栏
- 网页深色渲染（Android 10 及以上支持）
- 顶部太阳/月亮按钮可切换网页深色/原色显示
- 网址访问与 Google 搜索
- 前进、后退、刷新、主页
- 网页缩放与加载进度条

## 下载 APK
打开 [Actions](../../actions) 页面，进入最新成功的 Android APK Build 运行记录，在 Artifacts 下载 `MinimalBrowser-debug-apk`。

## 构建要求
Android Studio / Gradle 8.9 / JDK 17 / Android SDK 35。

最低 Android 版本：Android 6.0（API 23）。
