# Nightbird Browser

A minimal Android browser with a dark interface.

- Dark address/search bar and navigation controls
- DuckDuckGo search and direct URL navigation
- Back, forward, home, refresh
- Web page zoom
- Android WebView algorithmic darkening where supported

## Download APK
Open the repository's Actions tab and download the `Nightbird-debug-apk` artifact from the latest successful Android APK Build run.

## Build locally
Open this project in Android Studio with Android SDK Platform 35, or run:

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
Minimum Android version: 6.0 (API 23).
